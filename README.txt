ZERIN PORTFOLIO WEBSITE

1. Extract the ZIP file.
2. Open the zerin_portfolio folder in VS Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.
4. Before publishing, edit index.html:
   - Replace your-email@example.com with your real email address.
   - Replace the # social links with your Instagram, Facebook and LinkedIn profile URLs.
   - Add or adjust projects and skills to match your actual experience.

To publish free, upload the folder to GitHub and enable GitHub Pages, or drag the folder into Netlify Drop.
The portrait image is in assets/profile.jpg.
